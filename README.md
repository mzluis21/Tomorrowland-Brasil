🎶 Tomorrowland Brasil

Projeto Tomorrowland Brasil desenvolvido com foco em estudos de front-end, inspirado no maior festival de música eletrônica do mundo.
O site busca transmitir a identidade visual, energia e atmosfera do Tomorrowland, aplicando boas práticas de desenvolvimento web.

🌎 Sobre o projeto

O Tomorrowland Brasil é um projeto visual e educacional que simula um site informativo do festival, com o objetivo de praticar:

estruturação de páginas web

design visual inspirado em eventos reais

organização de arquivos

responsividade

versionamento com Git e GitHub

🚀 Tecnologias utilizadas

HTML5 – estrutura do site

CSS3 – estilização, layout e responsividade

JavaScript – interações e comportamento da interface

📂 Funcionalidades

Página inspirada no festival Tomorrowland Brasil

Layout moderno e organizado

Seções informativas sobre o evento

Estrutura preparada para futuras expansões

Organização clara entre HTML, CSS, JS e assets
